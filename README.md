# O Rei Macaco e a Grande Jornada

Livro infantil (8-12 anos) em português, adaptação de *Jornada ao Oeste*, escrito por Caio de Matos Vital. 20 capítulos, ~12.000 palavras. Ilustrado em aquarela tradicional, produzido em Canva.

## Arquivo canônico

**`o-rei-macaco-e-a-grande-jornada-ATUAL.md`** é sempre a versão mais atualizada do texto. Qualquer outra cópia (Canva, versões antigas) deve ser considerada desatualizada até confirmação.

## Estrutura do repositório

| Arquivo | O que é |
|---|---|
| `o-rei-macaco-e-a-grande-jornada-ATUAL.md` | Manuscrito completo, texto canônico |
| `ficha-estilo-rei-macaco.md` | Regras de estilo visual: técnica de aquarela, paleta, resolução (2400×3000px), regras de vinheta e do registro em lápis pra páginas de transição |
| `ficha-sun-wukong.md` | DNA visual do Sun Wukong — aparência, figurino por fase da história, escala |
| `ficha-zhu-bajie.md` | DNA visual do Zhu Bajie |
| `ficha-sha-wujing.md` | DNA visual do Sha Wujing |
| `ficha-mestre-tang.md` | DNA visual do Mestre Tang |
| `guia-ilustracoes-rei-macaco.md` | Prompts de cena por capítulo (parcialmente desatualizado — ver nota abaixo) |
| `prompts-cenas-sha-wujing-em-diante.md` | Prompts de cena do Cap. 13 em diante |
| `sunwukongaprovado.png`, `zhubajieaprovado.png`, `shawujingaprovado.png`, `tangaprovado.png` | Imagens de referência oficial de cada personagem — sempre anexar ao pedir uma nova ilustração |

## Como usar isso pra gerar uma ilustração nova

1. Leia a `ficha-estilo-rei-macaco.md` pra regras gerais
2. Leia a ficha do(s) personagem(ns) presente(s) na cena
3. Anexe a imagem "aprovado" de cada personagem como referência visual
4. Descreva a cena específica, com o trecho exato do texto que ela ilustra

## Notas de produção

- O livro é diagramado no **Canva** (fora deste repositório)
- Terminologia fixa: "**bastão**" é a arma do Sun Wukong (do Cap. 6 em diante); "**cajado**" é reservado só pro Mestre Bodhi
- Figurino do Sun Wukong muda ao longo da história — ver `ficha-sun-wukong.md` pra timeline exata
- Duas técnicas visuais coexistem: aquarela colorida cheia (padrão) e esboço a lápis puro, sem cor (reservado pra páginas de transição/fechamento silencioso — ver `ficha-estilo-rei-macaco.md`)

## Pendências conhecidas

- `guia-ilustracoes-rei-macaco.md` tem seções desatualizadas desde que as fichas de personagem foram separadas — as fichas individuais têm prioridade em caso de conflito
- Várias páginas do Canva ainda usam composições com texto integrado à imagem (gerado no ChatGPT) — mudanças no texto canônico não se propagam automaticamente pra essas, exigindo regeneração manual
